# Domänen-Notizen

## Definitionen

- **Consultant**: Mitarbeitende Ressource, typischerweise 40h/Woche Vertrag.
- **Allocation**: Geplante Stunden pro Consultant und Woche auf einem Projekt.
- **Capacity Override**: Anpassung der Wochenkapazität (z. B. Teilzeit, Sonderregelung).
- **Absence**: Abwesenheit (Krankheit, Urlaub), wirkt auf verfügbare Kapazität.

## Auslastungslogik

- Auslastung = geplante Stunden / (vertragliche Kapazität oder Override)
- Farblogik:
  - < 30%: rot
  - 30–60%: gelb
  - > 60%: grün
  - > 90%: blau (überbucht)
